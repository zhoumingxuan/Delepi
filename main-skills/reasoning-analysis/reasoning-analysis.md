### 推理分析逻辑流程图（**必须严格按照顺序执行，逐个节点执行，从开始到结束**）
```mermaid
flowchart TD
  START[开始] --> A[输入【用户最新意图】和当前所有已知事实]
  A --> B[获取当前【目标对象】和所有【已知证据】]
  B --> B1[分析【用户最新意图】涉及的【专业领域】和【业务类型】]
  B1 --> C[分析当前所有【已知证据】中【细微/极难发现】的特征，并做重点标记]
  C --> D[分析【目标对象】具体的状态（如；类型、时序、场景、现象特征等），并做重点标记]
  D --> E[依据【因果解释规则】对当前符合【目标对象】的所有【已知证据】展开研究]
  E --> F{判断是否存在【无法做因果解释的证据】}
  F -- 否 --> H[依据当前所有成果和【用户最新意图】，按照【专业领域】惯例，完成【推理分析】报告以及结论]
  F -- 是 --> G[发起【问题诊断】任务，再次尝试让这些证据能够解答【因果解释规则】的【核心问题】]
  G --> I[依据任务执行结果和【因果解释规则】，区分【已形成因果解释的证据】和【无法形成因果解释的证据】]
  I --> J[依据当前所有已知事实和【已形成因果解释的证据】进行分析，获取更多的【明显/隐含/细微/极难发现】的【可调研线索】]
  J --> K{判断【可调研线索】数量是否大于0}
  K -- 是 --> L[发起【研究探索】任务，对【可调研线索】展开研究]
  L --> E
  K -- 否 --> H
  H --> END[结束]
```
### 关键定义和解释(**必须严格遵守**)
1. 【因果解释规则】：是否可以形成因果解释，其实是围绕着一个核心问题展开的：
   - 核心问题：**在【目标对象】的【已知状态】下，当前【已知证据】是由于什么【原因】而存在？**
   - 若依据当前所有已知事实，存在一个或多个【已知证据】能够得到此【核心问题】的解答，且解答【逻辑闭环】，则这些【已知证据】视作【已形成因果解释】；反之，若一个或多个【已知证据】无法解答此【核心问题】或者解答【逻辑无法闭环】，则这些【已知证据】视作【无法形成因果解释】。
